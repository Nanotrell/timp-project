# Разработка приложения клиент-сервер

## О проекте

**Клиент-серверное приложение для построения графиков математических функций**

Проект представляет собой клиент-серверную систему для визуализации кусочно-заданных математических функций с возможностью динамического изменения параметров.

## Математическая функция

Функция задана тремя участками:

a * x², x < 0
x³ - 3x + b, 0 ≤ x < 2
c * (x⁴ - 4x³ + 4x²), x ≥ 2

## Основные возможности

- Регистрация и авторизация пользователей
- Восстановление пароля с генерацией кода
- Построение графика функции
- Изменение параметров a, b, c через ползунки
- Отображение таблицы с 20 точками
- Масштабирование и панорамирование графика
- Docker контейнеризация

## Технологии

- C++ / Qt (клиент и сервер)
- PostgreSQL (база данных)
- Docker (контейнеризация)
- Doxygen (документация)
